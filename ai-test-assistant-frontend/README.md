# admin-dashboard

This project is an admin dashboard built with React, TypeScript, and Tailwind CSS. It includes a login screen and integrates with an existing Python admin module.

## Features

- User authentication with a login form
- Protected routes for authenticated users
- Main dashboard interface
- Responsive layout with a header and sidebar navigation

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd admin-dashboard
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

## Usage

To start the development server, run:
```bash
npm start
```

Open your browser and go to `http://localhost:3000` to view the application.
